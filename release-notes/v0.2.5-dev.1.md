# 0.2.5-dev.1 — 三个内置流程模板

仅发布到 dev 开发分支，main 保持 classic 稳定版。

- 功能开发：需求分析 → 确认需求与方案 → 实现与自测 → 独立验证 → 最终验收；3 个角色、5 个节点。
- 问题排查与修复：复现与取证 → 根因分析 → 确认根因与修复范围 → 最小修复 → 独立回归验证 → 修复验收；3 个角色、6 个节点。
- 算子开发与优化：规格与基线 → 确认规格与指标 → 实现与优化 → 独立正确性验证 → 性能评测 → 算子交付验收；4 个角色、6 个节点。

每个节点包含通用要求、交付物和验收条件。各模板列出套用前需要提供的信息，不预填路径、参数、硬件或误差阈值；套用后仍由统一适配生成完整本次任务并经用户确认。

内置模板随插件加载，不写入个人模板文件；Gallery 标明内置或个人。内置模板不可覆盖或删除，可以编辑并另存为独立个人副本；来源为内置模板的流程也只能另存为个人模板。模板内容按稳定 ID 和版本读取。

验证：模板结构、完整通用字段、依赖、复制隔离和只读限制的回归测试；实际打包插件在 Harness 0.2.1-rc.2 中验证列表、个人副本保存、三种模板应用和未适配时禁止启动。快照见 scripts/fixtures/snapshots/builtin-templates.json。模型输出使用确定性 fixture；未对三个真实项目进行模型质量评测。
