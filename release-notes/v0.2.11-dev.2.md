# 0.2.11-dev.2 — 区分门控节点与验收节点（开发版）

本版本仅用于 dev；不改变 main 稳定版的功能范围。

- 左上方分别提供「门控节点」「验收节点」。门控使用菱形，内部选择人工审核或 AI 自动审核；验收使用普通矩形，沿用人工验收工作台。
- 图标同步区分：门控使用菱形问号，验收使用剪贴板勾选；创建入口、对象列表、画布与活动面板保持一致。
- 门控必须选择上游返回目标、连接返回线形成环路。未连接时可以保存要求和连线草稿，但不能完成配置、开始审核或运行。原节点进入下一轮，保留历史，不增加任务节点。
- 验收不通过时填写意见、选择返工起点，新建该任务及其受影响后续任务的路径。旧结果保留，新结果接回同一个验收节点，重新验收通过才放行下游；多次退回遵循同一规则。
- 验收历史保存当轮输入节点，画布以虚线展示已替换的历史输入连接。历史连线不参与依赖、派发或放行。
- 验收节点不再显示循环配置。节点类型随模板、提炼、恢复和重跑保留；旧流程中的循环检查点继续识别为门控，其他旧检查点显示为验收。

类型检查、构建和完整 pnpm verify 验证链通过，其中首组 213 项回归全部通过。新增检查覆盖两类节点的状态推进、连续返工、模板往返、旧数据兼容与审核面板渲染。浏览器工具因无法可靠识别 Windows 当前网址而停止；本次没有完成实机 UI 验收，也没有进行真实模型执行验证。
