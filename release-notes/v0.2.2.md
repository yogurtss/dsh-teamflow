# 0.2.2 — 首次规划生成双层任务

- Teamflow 原生规划必须为新任务同时生成通用层和本次层，遗漏时要求模型修正提案。
- 普通建队、创建任务和计划修改工具支持结构化双层字段；旧单层任务与配置保持兼容。
- 属性编辑只显示一份任务要求，执行记录独立折叠；提案不再重复显示编译后的 description，已保存资料与待确认修改明确区分。
- 通用层描述可复用方法和质量要求，本次层描述当前目标、文件与参数；修改仍由用户确认。

验证：前后端构建、81 项相关回归测试、核心检查、生命周期检查、README 版本和构建产物一致性检查通过。打包后的插件在真实 Harness 0.2.1-rc.2 中验证了首次双层规划、确认保存、模板提炼、算子 B 适配、执行和冷启动恢复，沿用凭据无关的模板快照。外部模型输出使用确定性 fixture；本轮未验证真实模型的文字质量或远程服务器界面。
