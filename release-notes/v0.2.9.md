# 0.2.9 — 审计策略跳过与证据失效分离

2026-11-09，按用户要求将本次 bug 修复同步到 main。稳定 Git 安装源仍为 `github:yogurtss/dsh-teamflow#main`；不发布 npm 包、不移动 classic 标签。

- 修复策略跳过被当成证据失效的问题：权重、不支持的格式和超限文件只列出路径、大小及原因，提示用户本机检查，不读取内容或生成摘要。
