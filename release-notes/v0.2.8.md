# 0.2.8 — 门控循环、成果归档与按需验收

2026-11-09，经用户授权将 dev 开发迭代提升至 main。稳定 Git 安装源为 `github:yogurtss/dsh-teamflow#main`。本次不发布 npm 包、不创建或移动版本标签。

- 支持有轮次和超时上限的人工/AI 门控循环、独立审核、PASS/REJECT 路径与不可变多轮历史。
- 新增算子持续优化、修复与回归循环模板，扩大 Workflow 状态卡片并展示进度详情。
- 人工验收可创建返工分支；新增后台执行的成果归档节点，保留结果、证据引用及可选文件副本。
- 卡片轮询不再扫描或哈希产物；打开验收材料时才后台读取，正式提交重新校验。
- 权重、压缩包及未知类型不读取内容；单文件审计最多 2 MiB，每次 scope 最多 32 MiB。受限文件显示元数据和未验证原因。
- 大文本预览只读取开头 256 KiB，标明截断且不生成整文件指纹。按需哈希缓存 TTL 为 5 秒；后台审计有超时与队列上限。
- 状态读取失败返回错误并保留上次卡片，避免将不完整响应当成团队删除。

详细设计与既有验证证据见[开发记录](./v0.2.8-dev.1.md)、[按需验收说明](../docs/on-demand-artifact-audit.md)、[归档说明](../docs/workflow-archives-2026-11-09.md)。宿主依赖和支持矩阵未变更。本次性能修复尚未在用户原先 55 秒的实际 DSH 场景中测量端到端延迟。
