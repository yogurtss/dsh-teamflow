# 0.2.12 — 门控循环进入稳定分支

- 画布和模板支持有限轮次的人工／AI 门控、定向返工、轮次对照，以及通过后生成成果归档。
- 节点卡片控制单个任务，循环框控制整组。外部输入完成时，排队循环若缺少配置会暂停并记录原因，上游结果仍可保存。
- 活动面板按可操作的人工审核统计提醒。人工门控可以审核失败结果，AI 门控通过后保留审核方式。

Git 安装使用 `github:yogurtss/dsh-teamflow#main`。Super Agent 在 `dev` 上开发。

验证覆盖完整的 36 个仓库检查步骤，以及隔离 Harness `0.2.1-rc.5` 的 HTTP 人工／AI 门控、模板目录和冷启动恢复。宿主使用固定模型响应。另从 Git 提取干净快照，验证了安装产物与源码摘要一致。
