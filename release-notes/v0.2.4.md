# 0.2.4 — 通用模板，具体执行

模板继续仅导出节点通用层、结构与成员职责，不保存本次任务或执行历史。首次规划、模板统一适配和一键 AI 拆分现在明确要求生成完整的本次任务书：具体化通用方法、交付物和验收约束，并纳入当前目标、输入与参数，不能只生成差异或引用通用层。

执行派发与领取任务只读取本次层；通用层保留在配置界面，用于模板复用和后续生成。旧单层任务保持原有执行行为。单纯的文本规则无法证明语义上没有遗漏约束，因此生成结果仍需用户确认。

旧版双层任务可能仅包含补充说明，尚未执行的任务读取时会标记待配置；请重新生成或核对完整要求后保存。通用要求、节点目标或团队目标变化也需重新确认本次要求。已执行历史不改写，运行中任务不强制停止。确认记录只保存执行契约版本及生成时的团队目标，不写入模板。

模型体验：生成提示增加“执行 Agent 只读本次层”的要求，位于 src/workflow-native.ts、src/task-layers.ts、src/task-split.ts 和 Captain usage 提示。执行文本不再拼接通用层，减少重复输入；生成会话仍需要两层上下文。提示更新会改变对应请求前缀；本次层变化会改变派发与领取文本。

验证：前后端构建、模板／迁移回归、工作流和编辑器回归、核心及生命周期检查。打包后的真实 Harness 0.2.1-rc.2 验证模板保存、适配、确认、实际派发与领取、拆分和冷启动；模型输出使用确定性 fixture，未测试真实模型的语义覆盖质量或远程服务器界面。更新的模板和拆分快照位于 scripts/fixtures/snapshots/。
