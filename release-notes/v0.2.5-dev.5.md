# 0.2.5-dev.5 — 重跑到指定下游节点

仅 dev 开发版本；main / classic 不变。

- 在任意因上游重跑而挂起的节点属性中选择“重跑到此节点”，一次安排该节点及其必要上游中的待重跑任务。
- 调度器按依赖顺序执行，独立分支可以并行；正在执行的上游保留当前轮次，已完成且有效的前置不重复执行。
- 人工检查仍等待用户确认，确认后已安排的下游自动继续；目标之外的待重跑分支保持暂停。
- 点击前展示范围；未保存属性、未完成配置、失败/退回未处理、停止中或手动暂停会阻止操作并提示原因。整个路径在同一团队锁和版本校验下确认，避免部分放行。
- 中英文同步。保留原单节点恢复接口以兼容旧调用。
