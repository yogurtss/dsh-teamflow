Stable Git installation: github:yogurtss/dsh-teamflow#main. Development remains on dev; classic is unchanged.

- Reuse bounded workflow, discussion and template display caches while refreshing authoritative state. Coalesce concurrent reads, bound stalled requests and prevent stale navigation from overriding the latest Agent selection.
- Move activity workspace hashing to a worker and scope polling to the selected captain. Preserve exact evidence checks, task execution and state synchronization.
- Reduce repeated discussion-history conversion and unchanged payload transfer. Native Agent transcript hydration remains owned by DSH; remote server latency has not been measured.
- Allow separate Gallery Skill / MCP access per member, preserved in templates and cold restores. Requires the companion Gallery member-access interface (tested upstream revision bfde24cea2d8f51b6fd705ee2838597c086fa7d5). Legacy omitted flags retain existing behavior.
- Fix template extraction after Gallery integration: model-facing examples now conform to the strict tool schema; the server preserves human-configured permissions independently of model output.

Git promotion does not publish npm packages or update installed user profiles. Compatibility policy and exact supported hosts remain unchanged. See the [loading audit](../docs/performance-0.2.7/loading-audit.md).
