# 0.2.10 — 审计范围与读取边界修复

2026-11-09，按用户要求同步 dev 和 main。本次不发布 npm 包，不修改 classic 标签。

- 在展开全部声明目录后，按固定路径顺序分配内容审计预算，避免仅声明顺序或目录拼写变化导致验收证据变化。
- 修复恰好达到 200 文件时，重叠目录或重复目录被误判为扫描不完整。
- 将成果预览移入已有的有界后台 worker；仍按需读取，保留截断、路径检查、超时和在途合并，避免同步读盘占用宿主线程。
- 修复历史材料中 0.2.8 策略拒绝仍显示为文件不存在/读取失败的问题；真实 I/O 失败仍保留。
- 归档清单在读取前检查普通文件类型和 20 MiB 上限，并限制读取期间增长；保留摘要校验。
- 归档界面及工具说明改为实际有效限制：仅复制支持的可审计文件，单文件 2 MiB、总计 32 MiB；策略排除项只保存元数据。

验证：构建和完整验证链 36 项全部通过；隔离 Harness 0.2.1-rc.5 使用本版 tarball 通过 HTTP 成果预览、人工审批、人工/AI 循环、归档与冷启动恢复。模型响应为固定测试样本。尚未在用户实际 55 秒场景中测量更新后的端到端延迟。
