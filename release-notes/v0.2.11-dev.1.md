# 0.2.11-dev.1 — 全面检查后的状态修复（开发版）

本版本属于 dev 循环测试分支；main 保持原流程功能范围，通用修复单独移植。

- 暂停整个流程时取消尚在等待输入的循环排队，避免输入到达后自动启动。
- 流程编辑令牌绑定循环状态，卡片控制令牌包含排队标志，拒绝过期操作。
- 单个团队损坏或读取失败不再阻塞其余团队的循环超时与停止处理。
- 归档时记录成员是否应恢复，恢复时保留主动移除的成员；旧归档缺少区分信息时保留旧兼容行为。
- 忽略重复或过期的流开始帧，防止正在显示的回复被清空。

已用新增回归测试复现修复前的五类问题；检查范围还包括重跑、审批权限、持久化、模板库、消息投递和前端异步状态。构建、完整验证链 36 项通过；开发 tarball 在隔离 Harness 0.2.1-rc.5 通过人工/AI 循环、审批、归档及冷恢复。模型响应使用固定样本。
