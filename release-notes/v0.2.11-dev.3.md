# 0.2.11-dev.3 — 允许修改空闲 Agent 的模型（开发版）

本版本仅用于 dev，不变更 main 稳定版。

- 修复循环已经通过或结束，修改成员模型仍提示「请先结束循环再修改其成员」的问题。
- 编辑成员配置不再受循环状态限制：待启动、执行中、等待审核、暂停、通过和结束均可编辑空闲成员；其他成员忙碌不阻止当前成员修改。
- 团队整体停止时也允许只更新成员配置，不恢复团队、不更改任务拓扑、不启动执行。混合修改任务或删除成员仍遵循原有流程限制。
- 目标成员有已领取或执行中的任务、任务交接中、正在停止，或宿主会话仍在运行时拒绝保存。模型修改沿用原有校验与会话退役机制，下一次执行使用新配置，已保存的循环历史不改写。

类型检查与构建通过；循环、工作流及工作台 119 项回归通过。新增测试覆盖各循环状态、停止中的团队、目标成员忙碌判断，以及实际 HTTP 保存、旧会话退役、历史模型记录和仍运行会话的拒绝路径。未进行真实模型或浏览器交互验证。
