# DSH TeamFlow 0.2.1

Fixes the missing Teamflow entry in a new DSH Web conversation.

The host deliberately hides title-adjacent header actions while a session is blank. The earlier standalone preview did not exercise that condition. Blank conversations now receive an additive shell-layer entry at the top right; selecting it opens Gallery without sending a message or generating a team. Once the conversation starts, the ordinary header action takes over. Ordinary registration no longer depends on optional right-sidebar services. The host sidebar toggle is preserved.

Validated against the real local Harness Web 0.2.1-rc.2: new blank session, visible entry, direct Gallery opening, and navigation away from the conversation. Added tests that execute the installed host header implementation with hideChrome on/off and verify session visibility transitions. No inference/API credentials are needed for this UI check.

The runtime fixture's template-directory override now targets the actual teamflow plugin ID, so its records stay inside the isolated test directory.

See [local Web verification](../docs/web-entry-fix-2026-10-30/README.md). Update the installed Git/local package on the server, fully restart dsh web, then hard-refresh the browser. This patch does not publish to npm.
