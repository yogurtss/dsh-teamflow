## 保留的通用优化

普通卡片轮询不扫产物；按需后台审计与预览；类型/大小/总预算/扫描总量限制；5 秒有界哈希缓存；策略跳过单独呈现；固定路径顺序分配预算；重复范围去重；文件读取期间变化检查；Windows 短暂截断写入重试；请求取消、去重及状态缓存。

## 检查与验证

检查了调度与成员停止、暂停与重跑、循环生命周期、持久化、模板解析和存储、原生讨论权限、消息投递、前端异步状态与流显示。main 与 dev 分别构建，分别通过完整验证链的 36 个命令；两种 tarball 分别在隔离 Harness 0.2.1-rc.5 运行各自适用的 HTTP 与冷启动场景，使用固定模型响应。

这不是对所有运行环境都无 bug 的保证。用户原先 55 秒场景的端到端延迟尚未在实际实例测量；旧归档的成员移除来源无法从缺失的信息中重建。
